# Book Club Project

A full-stack application for managing a book club with React frontend and Flask backend.

## Features

- Book listings
- User management
- Discussion forums

## Setup

### Prerequisites

- Python 3.8+
- Node.js
- Pipenv

### Backend Setup

1. Install dependencies:
   ```bash
   pipenv install
   ```

2. Run the server:
   ```bash
   pipenv run python server/app.py
   ```

### Frontend Setup

1. Navigate to client directory:
   ```bash
   cd client
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```
